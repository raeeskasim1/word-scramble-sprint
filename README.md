# Word Scramble Sprint

Unscramble a small set of AI and data terms, with a hint when a word gets stubborn.

## Run

Open `index.html` in a modern browser. HTML, CSS, and JavaScript are all in that file. No server, packages, internet connection, API key, build step, or downloaded model is required.

## Try it

Finish a ten-word run, use a hint, and restart with a new order.

## How it works

A shuffled term list and Fisher–Yates letter shuffle create ten puzzles. Matching is case-insensitive, hints describe each term, and skipped words add no score. The definitions are short learning cues rather than a technical knowledge assessment.
